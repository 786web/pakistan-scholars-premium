# Pakistan Scholars High School

A responsive school website for Pakistan Scholars High School, Bherowal and Bhoa Hassan campuses.

## Run locally
Open `index.html` in a browser. No build step is required.

## Deploy
Import this repository into Vercel. It is a static HTML/CSS/JavaScript site and can be deployed with the default settings.
